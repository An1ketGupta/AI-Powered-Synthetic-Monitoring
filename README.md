# EdgeWatch

AI-powered synthetic monitoring and incident intelligence, built entirely on Cloudflare's edge platform.

> Register URLs/APIs to watch. EdgeWatch checks them from the edge on a schedule, detects
> outages and anomalies, and uses Workers AI to write a human-readable incident report —
> including which past incidents it resembles — instead of just flipping a status dot red.

Full architecture, feature list, and deploy instructions are being written as the project
comes together — see `worker/` and `dashboard/` for the current state.
